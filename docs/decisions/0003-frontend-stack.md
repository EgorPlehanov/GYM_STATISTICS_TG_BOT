# 0003. React/Vite SPA

## Статус

Принято.

## Контекст

Web-версия является личным кабинетом с приватными тренировочными данными. Ей нужны графики, формы, фильтры, календарь, мобильный интерфейс и поддержка Telegram Mini App.

SEO не является важным требованием, потому что основная часть приложения доступна после авторизации.

## Решение

Используем React/Vite/TypeScript как SPA.

Frontend размещается в каталоге:

```text
web/
```

Рекомендуемая структура:

```text
web/src/app
web/src/pages
web/src/widgets
web/src/features
web/src/entities
web/src/shared
```

## Почему не SSR

SSR полезен, когда важны SEO, быстрая отдача публичных страниц и серверный рендеринг контента для поисковиков.

Для этого проекта ключевой сценарий - авторизованное приложение с личными данными. Поэтому SPA проще, дешевле в поддержке и хорошо подходит для Telegram Mini App.

## Последствия

- Нужно настроить API client и session handling.
- Нужно отдельно продумать отдачу статической сборки на VPS.
- Нужно тщательно проверить мобильный UX внутри Telegram WebView.
